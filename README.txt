=================================================
Project: State Minimization using Implication Table
=================================================

Language: C Programming Language

Project Description:
This program minimizes State tables
using the Implication Table Method.

The program supports both:

1. Moore Machines
2. Mealy Machines

Features:
- User input for state names
- State transitions input
- Output input
- Implication table generation
- Equivalent state detection
- Reduced state table generation
- Support for both Mealy and Moore models

Files Included:
- main.c       : C source code
- main.exe     : Executable version of the program
- README.txt   : Documentation and instructions

Recommended Compiler:
- GCC
- CodeBlocks (MinGW GCC)
- Visual Studio Code with GCC

Program Assumptions / Notes:
- Maximum number of states = 30
- Maximum number of inputs = 10
-❗The program assumes valid user input 
  and is not designed to handle unexpected 
  or invalid inputs.
